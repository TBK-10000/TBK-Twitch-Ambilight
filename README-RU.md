# TBK Twitch Ambilight 3.0.2

Рейтинг подарочных подписок и другие карточки верхней карусели используют общий фон чата. Обычный текст и стрелки учитывают его контраст; цветные надписи, значки и индикаторы сохраняются. Выключение оформления чата возвращает штатные фоны.

Исправлено перекрытие сообщений: пустой служебный контейнер карточки пользователя остаётся прозрачным. Оформление применяется к самой открытой карточке. После обновления перезагрузите расширение в opera://extensions и обновите Twitch.

Расширение для Opera GX добавляет подсветку вокруг видео Twitch, оформление чата и читаемые окна. Версия 3.0.2 принята как обычный выпуск для ручной установки. Инструкция на английском — README-EN.md.

## Установка и обновление

1. Распакуйте ZIP в постоянную папку.
2. В opera://extensions включите «Режим разработчика» и нажмите «Загрузить распакованное расширение».
3. Выберите TBK-Twitch-Ambilight, где находится manifest.json.
4. Обновите Twitch и запустите видео. Появятся переключатель ON/OFF и шестерёнка TBK.

Для обновления сначала экспортируйте настройки, замените файлы в прежней папке, перезагрузите карточку расширения и обновите Twitch. Настройки 2.2.7 мигрируют автоматически. При новой папке импортируйте прежний экспорт; старое расширение отключите, чтобы не получить две подсветки. Для переноса между браузерами используйте экспорт и импорт: настройки хранятся отдельно в каждом браузере. Node.js и сборка для установки не нужны.

## Управление и эффекты

ON/OFF рядом с шестерёнкой полностью выключает эффекты видео, чата и окон, возвращая оформление Twitch. Настройки сохраняются, шестерёнка остаётся доступна. Надпись дополняет цвет состояния; переключатель работает с клавиатуры. Меню содержит раскрывающиеся тематические разделы.

Шесть эффектов: классический, мягкое и направленное свечение, растекание цвета, лучи и волны. Шейдерные эффекты требуют рабочего WebGL. При Canvas 2D или недоступности GPU применяется классический эффект с пояснением в диагностике. Для движущихся эффектов отдельный ползунок скорости: ноль останавливает движение, цвет продолжает обновляться по видео.

Сохранены цвет, размытие, распространение, слои, сглаживание, частота, определение чёрных полос и уменьшение видео. Мягкий переход действует снаружи картинки, не размывая видео. Базовые настройки и переопределения «Кинотеатр» / «Полный экран» независимы.

Оформление чата включается отдельно, использует правый край общего кадра. Для объявлений, карточек, списка зрителей и меню доступны обычный читаемый стиль, матовое стекло и стекло с преломлением. Настраиваются плотность, размытие, преломление и слабые блики; текст и кнопки остаются резкими. Обычный стиль используется по умолчанию.

## Экономичный режим

Переключатель находится в настройках. Заводской набор: классический Canvas 2D, один слой, качество 25%, 15 FPS, пауза в фоновой вкладке. Выключение возвращает прежний пресет или основные настройки.

Обычная правка параметра автоматически выходит из экономии и меняет восстановленный набор. Кнопка «Редактировать экономичный режим» позволяет настроить сам экономичный набор; завершение сохраняет его. Есть сброс к заводским значениям. Изменённый пользователем набор может потреблять больше ресурсов.

## Пресеты и перенос

Внизу меню — блоки с названием, переключателем справа и кнопками переименования, удаления, копирования и вставки. «+» создаёт блок из текущих применённых параметров, включая экономию. До 32 пресетов.

Активен один пресет; правки автоматически записываются в него. Выключение или удаление активного возвращает независимые основные настройки. Каждый блок содержит подсветку, чат, окна и профили режимов; общий ON/OFF и включение экономии независимы.

«Копировать» помещает JSON параметров в буфер. «Вставить» заменяет параметры выбранного блока, сохраняя имя; неверные данные ничего не меняют. При отказе Clipboard API предлагается ручное копирование/вставка. Полный экспорт включает все наборы и состояния; поддержан импорт прежних экспортов.

## Режимы и ограничения

На реальном Twitch в Opera GX проверены live, публичный VOD, кинотеатр, полный экран и player.twitch.tv в iframe. Доступ к VOD зависит от настроек канала: некоторые записи доступны только подписчикам.

Перенос в Chrome проверен в официальном Chrome for Testing: реальный MV3, эффекты, настройки, пресеты, экономичный режим, PiP, пиксели чата и окон; на публичном Twitch — эфир, VOD, кинотеатр, полный экран, iframe и карусель.

Отдельный пункт PiP управляет подсветкой исходной страницы; по умолчанию выключен. Плавающее окно не получает эффектов. Творческая студия и отдельный popout-чат исключены.

Браузер может запрещать чтение кадров клипов или защищённого видео. Тогда свет останавливается с диагностикой, воспроизведение сохраняется. Отдельная реализация для таких клипов исключена пользователем. Другие браузеры и магазины — следующие задачи.

## Диагностика и хранение

При отсутствии света обновите Twitch, проверьте ON/OFF и доступ расширения к сайту. В меню можно выбрать Canvas 2D, повторить запуск и выгрузить диагностику. Сообщение о запрете чтения кадров означает ограничение источника/браузера.

Настройки: chrome.storage.local, ключ tbk.twitch.ambilight.v2, схема 3. Облачной синхронизации нет. Разрешение расширения — storage; сетевых разрешений для обхода защиты нет. Авторство и лицензии сохранены в LICENSE и THIRD-PARTY-NOTICES.md.
